Privacy Policy: HoopDream Uploader

Last updated: October 18, 2026

Who this covers

HoopDream Uploader is a private tool run by the owner of the YouTube channel @theHoopDream. Its only user is that owner, signing in with their own Google account.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data it accesses

  • Basic channel information (channel name, handle and ID), to confirm it is posting to the right channel.
  • The videos it uploads, and their title, description, tags, category, privacy and processing status.

It does not read comments, messages, subscribers, viewing history or any other account data.

How the data is used and stored

  • The sign-in token is stored only on the owner's own computer, in a file only that user can read.
  • Upload records (video ID, title, time, status) are kept in a local log file on the same computer.
  • No data is stored on any server run by this tool.

Sharing

No data is sold, shared with or disclosed to anyone. Videos and their details are sent only to YouTube, to the signed-in user's own channel.

Cookies and tracking

This tool and this website use no cookies, analytics or tracking.

Revoking access

You can remove this tool's access to your Google account at any time at Google security settings. Deleting the local token file also stops all access.
